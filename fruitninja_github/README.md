# 🍉 Fruit Ninja - Air Mouse Edition

A browser-based **Fruit Ninja** web game featuring a phone-based **Motion Air Mouse Controller**.

## 📱 Features
- **Phone as Air Mouse**: Uses your phone's **Gyroscope** and **Accelerometer** to aim and slice fruits across the screen.
- **Cross-Network Compatibility**: Powered by WebRTC DataChannels (with Google STUN servers), allowing phone and PC to connect from different Wi-Fi or cellular networks.
- **Dynamic Slicing**: Wave/flick your phone or hold the slice button to cut fruits and combos.
- **Direct Touch Slicing Support**: Touchpad mode supported on the phone controller.
- **Calibration Flow**: Point at your PC screen and calibrate your neutral center position before game launch.
- **Combo & Critical System**: Slice multiple fruits in one swipe to rack up high scores.

## 🚀 Deployment / Usage
- **Standalone**: Open `index.html` on a desktop browser.
- **Netlify / GitHub Pages**: Deploy all files in this directory directly as a static web site.
- **Phone Controller**: Scan the generated QR code or open `controller.html` on your mobile browser.
